### Verification and Testing Methods

To verify the tool's effectiveness in preventing search engine indexing, we compare search results to demonstrate that—while the page itself is indexed—the random links within it are not, and the sensitive content contained within those random links remains invisible.

#### Experimental Steps

1.  Provide a publicly crawlable page, such as this blog post.
2.  Place **Marker A** on the page: a unique plain-text string that Google will naturally index.
3.  Place **Marker B** on the page: a random link generated by HideText from a piece of sensitive content.
4.  Wait 1–2 weeks to allow search engine crawlers (such as Googlebot) to crawl and index the page.

#### Verification Steps

1.  Search for Marker A; this should return this blog post. This proves the page **has indeed** been indexed.
2.  Search for Marker B; this should return **zero results**. This proves that search engines ignore this random link.
3.  Search for the sensitive content hidden within the random link; this should return **zero results**, proving that the tool effectively hides the content.
